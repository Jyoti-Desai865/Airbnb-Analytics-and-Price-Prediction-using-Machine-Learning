# Airbnb-Analytics-and-Price-Prediction-using-Machine-Learning

This project focuses on analyzing Airbnb listing data using data analytics, machine learning, and visualization techniques. The project includes data cleaning, exploratory data analysis (EDA), predictive modeling, Power BI dashboard creation, and implementation of an end-to-end analytics pipeline.

Problem Statement:
The rapid growth of Airbnb listings generates a large amount of data related to pricing, room types, customer ratings, and booking availability. Analyzing this data manually is difficult and time-consuming. The objective of this project is to analyze Airbnb listing data, identify business insights, and build a machine learning model to predict listing prices.

Data Source:
The dataset used in this project is the Airbnb Listings Dataset collected from Kaggle. The dataset contains information such as city, room type, property type, price, bedrooms, accommodates, customer ratings, and instant booking availability.

Methodology:
The project followed an end-to-end analytics workflow:
Extract → Transform → Load → Predict → Visualize
Steps Included:
Data Extraction using Pandas
Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Machine Learning Price Prediction
Power BI Dashboard Development
End-to-End Analytics Pipeline

Technologies Used:
Python
Pandas
NumPy
Matplotlib
Scikit-learn
Power BI

Key Findings:
Entire homes/apartments have higher average prices compared to private rooms.
Major cities contain the highest number of Airbnb listings.
Most Airbnb listings have high customer ratings.
Features such as bedrooms and accommodates influence listing prices.
Interactive dashboards provide better visualization of pricing trends and customer insights.

Results:
Successfully cleaned and preprocessed the Airbnb dataset.
Performed Exploratory Data Analysis to identify important trends and patterns.
Implemented a Linear Regression model for price prediction.
Evaluated model performance using MAE, MSE, and R² Score.
Developed an interactive Power BI dashboard with KPI cards, charts, treemaps, and slicers.
Implemented an end-to-end analytics pipeline for workflow automation.

Conclusions:
This project demonstrated the practical application of data analytics, machine learning, and visualization techniques for solving real-world business problems. The Airbnb dataset was successfully analyzed to identify trends, pricing patterns, and customer preferences. The project also showcased the importance of dashboards and end-to-end analytics pipelines in supporting data-driven decision-making.
