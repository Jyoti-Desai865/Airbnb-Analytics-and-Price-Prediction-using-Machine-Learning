# Airbnb-Analytics-and-Price-Prediction-using-Machine-Learning

This project focuses on analyzing Airbnb listing data using Data Analytics, Machine Learning, and Power BI visualization techniques. The Airbnb dataset was collected from Kaggle and processed using Python libraries such as Pandas, NumPy, Matplotlib, and Scikit-learn.

The project includes data cleaning, exploratory data analysis (EDA), predictive modeling, and creation of an interactive Power BI dashboard. A Linear Regression model was implemented to predict Airbnb listing prices based on features such as bedrooms, accommodates, review scores, and instant booking availability.

An end-to-end analytics pipeline was also implemented following the workflow:
Extract → Transform → Load → Predict → Visualize.

Features of the project:
• Data Cleaning and Preprocessing  
• Exploratory Data Analysis (EDA)  
• Machine Learning Price Prediction  
• Interactive Power BI Dashboard  
• KPI Cards and Visualizations  
• End-to-End Analytics Pipeline  

Technologies Used:
• Python  
• Pandas  
• NumPy  
• Matplotlib  
• Scikit-learn  
• Power BI  

This project demonstrates the practical application of business analytics, machine learning, and dashboard visualization for generating business insights and supporting data-driven decision-making.
